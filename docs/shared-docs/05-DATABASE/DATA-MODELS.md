# Leaf Database: Data Models, Value Objects & Domain Contracts

## 1. Executive Summary
This document specifies the domain entity definitions, value objects, and type enumerations utilized throughout Leaf. It establishes the bridge between Android Room persistence entities, Kotlin domain representations, and the native Swift models to be developed for iOS.

## 2. Core Value Objects & Enums

### 2.1 The `Amount` Value Object
- **Purpose**: Prevents floating-point rounding errors by wrapping integer subunits.
- **Kotlin**:
  ```kotlin
  @JvmInline
  value class Amount(val subunits: Long) : Comparable<Amount>
  ```
- **Swift**:
  ```swift
  struct Amount: RawRepresentable, Equatable, Comparable, Hashable, Codable {
      let rawValue: Int64
      init(rawValue: Int64) { self.rawValue = rawValue }
      init(_ subunits: Int64) { self.rawValue = subunits }
      
      static let zero = Amount(0)
      var isZero: Bool { rawValue == 0 }
      var isPositive: Bool { rawValue > 0 }
      var isNegative: Bool { rawValue < 0 }
      
      static func + (lhs: Amount, rhs: Amount) -> Amount { Amount(lhs.rawValue + rhs.rawValue) }
      static func - (lhs: Amount, rhs: Amount) -> Amount { Amount(lhs.rawValue - rhs.rawValue) }
      static func < (lhs: Amount, rhs: Amount) -> Bool { lhs.rawValue < rhs.rawValue }
  }
  ```

enum TransactionType: String, Codable, CaseIterable {
    case income = "INCOME"
    case expense = "EXPENSE"
    
    var displayName: String {
        switch self {
        case .income: return "Income"
        case .expense: return "Expense"
        }
    }

## 4. Entity vs. Domain Model Mapping Matrix

| Domain Model | Android Room Entity | Relation Helper Class | Primary Key | Foreign Key Dependencies |
| :--- | :--- | :--- | :--- | :--- |
| `Transaction` | `TransactionEntity` | `TransactionWithCategory` | `id: Long` | `category_id -> categories.id` (RESTRICT) |
| `Category` | `CategoryEntity` | Direct mapping | `id: Long` | None |
| `RecurringTransaction` | `RecurringTransactionEntity` | `RecurringWithCategory` | `id: Long` | `category_id -> categories.id` (RESTRICT) |
| `SplitExpense` | `SplitExpenseEntity` | `SplitExpenseWithDetails` | `id: Long` | `category_id` (RESTRICT), `group_id` (SET NULL) |
| `SplitParticipant` | `SplitParticipantEntity` | Embedded in `SplitExpense` | `id: Long` | `split_expense_id -> split_expenses.id` (CASCADE) |
| `SplitGroup` | `SplitGroupEntity` | Direct mapping | `id: Long` | None |
| `Budget` | `BudgetEntity` | `BudgetWithCategory` | `id: Long` | `category_id -> categories.id` (SET NULL) |
| `SavingsGoal` | `SavingsGoalEntity` | `SavingsGoalWithContributions` | `id: Long` | None |
| `SavingsGoalContribution`| `SavingsGoalContributionEntity`| Embedded in `SavingsGoal` | `id: Long` | `goal_id` (CASCADE), `transaction_id` (SET NULL) |
| `Reminder` | `ReminderEntity` | Direct mapping | `id: Long` | None |
