Important Upgrade Notice

Before Installing Leaf 1.1.4 on Android

We have updated the app's release-signing setup to establish a permanent, secured signing key for all future Android releases.

New to Leaf? If you are installing Leaf for the first time, no migration steps are required. Simply download and install the official APK below!

Updating from an earlier version? Android protects your device by ensuring that application updates are signed by the same digital key as the currently installed version. Because older test builds used a temporary signing configuration, Android may refuse to install version 1.1.4 directly over your existing installation (showing an update conflict or "App not installed" message).

How to safely migrate without losing your data:
  1. Back up your data first: Open your currently installed Leaf app, navigate to Settings → Data & Tools → Local & Cloud Backup, and tap "Create Local Backup". Choose a folder on your device or SD card to save your structured JSON backup file.
  2. Verify your backup: Confirm that the JSON backup file exists in your file manager or Google Drive before proceeding. Never uninstall without verifying a backup file first!
  3. Uninstall the older version: If Android blocks the v1.1.4 update, uninstall the older version from your phone only after your backup is securely verified.
  4. Install Leaf v1.1.4: Download and install the official v1.1.4 APK package from this page.
  5. Restore your records: Open Leaf v1.1.4, return to Settings → Data & Tools → Local & Cloud Backup, tap "Restore from Local File", and select your JSON backup file. All your transactions, ledgers, categories, and settings will be restored instantly.

Starting from version 1.1.4, future Android releases will use this secured signing identity so that this signing mismatch will not affect subsequent updates.

Your data matters. Always keep a backup before updating.

  • Unsigned IPA Package: This file cannot be installed directly in Safari by tapping download. It must be sideloaded using tools like AltStore, Sideloadly, or Xcode.

October 2026

Version 1.1.4 delivers full feature parity across Android and the reference iOS architecture, introducing isolated Separate Cash and Account Ledgers, complete internal ledger fund transfers, and native Android Home-Screen Widgets mirroring iOS interactive widgets.

Android Guide

Step-by-step Android installation guide

Because Leaf is distributed directly via GitHub, Android requires a one-time permission to install APK packages.

  1. 1

    Download APK

    Tap the Download for Android (APK) button above to save the verified Leaf_v1.1.4.apk onto your Android device.

  2. 2

    Check Backup (If Updating)

    If updating from an earlier version, take a local backup first via Settings → Data & Tools → Local & Cloud Backup → Create Local Backup.

  3. 3

    Allow Unknown Apps

    If Android prompts "Install unknown apps", tap Settings and toggle on Allow from this source for your browser or file manager.

  4. 4

    Complete & Restore

    Tap Install. If updating required uninstalling older builds, simply open Leaf v1.1.4 and tap Restore from Local File.

iOS Sideloading Guide

How to sideload Leaf on iPhone (Unsigned IPA)

Follow these straightforward steps to sideload the experimental Leaf IPA using AltStore or Sideloadly.

  1. 1

    Download IPA

    Download the unsigned package Leaf-v1.1.4-Sideloading-Unsigned.ipa to your Mac, Windows PC, or iPhone.

  2. 2

    Connect Sideloading Tool

    Open AltStore (on device) or Sideloadly (on your PC/Mac) with your iPhone connected via USB or Wi-Fi sync.

  3. 3

    Sign with Apple ID

    Drag the downloaded IPA into the sideloading tool and sign with your personal Apple ID to install the app on your device.

  4. 4

    Trust Developer

    On your iPhone, navigate to Settings → General → VPN & Device Management, select your Apple ID, and tap Trust.

You do not need to manually check this website for updates in the future. Leaf for Android includes an integrated in-app update checker located in Settings → App Updates.
