What's New

Leaf v1.1.4 — Separate Cash & Account Ledgers, Home-Screen Widgets & Feature Parity

October 2026

Version 1.1.4 delivers full feature parity with the reference iOS architecture, introducing isolated Separate Cash and Account Ledgers, complete internal ledger fund transfers, and native Android Home-Screen Widgets mirroring iOS interactive widgets.

  • Separate Cash & Account Ledgers: Physical cash-in-hand and electronic bank accounts now operate as independently tracked ledgers with isolated balances, filtered ledgers hub, and dedicated transaction history.
  • Atomic Internal Fund Transfers: Transfer funds seamlessly between Cash and Account with atomic counterpart pairing. Internal transfers remain strictly balance-neutral on overall liquid net worth and are excluded from income and expense metrics.
  • Dashboard Balance Breakdown Pills: The signature hero balance card now features interactive Cash and Account pill chips, providing an instant visual breakdown of liquid funds and 1-tap navigation to the Ledgers Hub.
  • Full Android Widget Suite (iOS Feature Parity): Complete native home-screen widget parity including Small (2x2 / 2x1 glanceable balance), Medium (4x2 budget progress & quick actions), and Large (4x4 comprehensive budget hub) with interactive privacy concealment.
  • Database Migration 10 → 11: Seamless SQLite schema evolution adding payment method categorization, transfer pairing, and indexing while 100% preserving historical data and existing user records.
  • Split 2.0 & Cross-Platform Architecture: Retains full Item-Level Custom Splitting, integrated financial calculator, contact picker, and offline-first security across both Android and iOS editions.
How To Install

Step-by-step Android installation guide

Because Leaf is distributed outside Google Play, Android requires a one-time permission to install APKs.

  1. 1

    Download APK

    Tap the Download Official APK button above to save the latest release file onto your Android device.

  2. 2

    Open the File

    Once downloaded, tap the notification in your notification bar or open the APK from your browser's Downloads menu.

  3. 3

    Allow Source

    If Android displays "Install unknown apps", tap Settings and toggle on Allow from this source.

  4. 4

    Complete Install

    Return to the installer dialog and tap Install. Leaf is now ready to use offline.

Future Updates

Built-in APK update checker

You do not need to manually check this website for updates in the future. Leaf includes an integrated in-app update checker located in Settings → App Updates.

When a new version is released on GitHub, the app can discover the update, stream the download with progress indicators, verify the SHA-256 checksum and package archive, and hand off installation to Android seamlessly.

In-App Updates Workflow

  • Automated release detection from official GitHub API
  • SHA-256 integrity verification before prompting install
  • Downgrade rejection and package identity checks
System Requirements

Compatibility & Specs

Android OS

Requires Android 8.0 (API level 26 — Oreo) or higher. Fully compatible with Android 9 through Android 15.

Storage

Lightweight footprint. APK download is ~4.3 MB, requiring under 18 MB of on-device space after installation.

Google Services

Google Play Services is not required for core offline tracking. Google services are used only if you choose to enable optional Google Drive backups.
