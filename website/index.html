Updating to Leaf 1.1.4?

Before updating, please save a backup of your expenses and important data. This helps keep your information safe while moving to the latest version.

How to save and restore your backup

How to save your backup

  1. Open Leaf.
  2. Go to Settings.
  3. Open Data & Tools.
  4. Select Local & Cloud Backup.
  5. Tap Create Local Backup.
  6. Make sure the backup file is safely saved before proceeding.

How to restore your data

  1. Install Leaf 1.1.4.
  2. Open Settings.
  3. Go to Data & Tools.
  4. Open Local & Cloud Backup.
  5. Select Restore from Local File.
  6. Choose your saved backup.
If you're installing Leaf for the first time, you can simply download and install it.
If your update does not install, make sure your backup is safely saved before removing your previous version and installing Leaf 1.1.4.

FAQ

Frequently asked questions

Quick, straightforward answers about using Leaf.

What is Leaf?

Leaf is a simple, private personal finance app designed to help you track daily spending, split shared bills with friends, plan monthly budgets, and reach savings goals — all without ads, trackers, or required account sign-ups.

Is Leaf free to use?

Yes, Leaf is completely free and open source. There are no subscriptions, in-app purchases, or locked features.

How can I download Leaf on Android?

Tap the Download for Android button above to download the official application file. When prompted by your phone, allow permission to install from your browser or file manager, and tap Install.

Is Leaf available on iPhone?

An experimental iPhone version is available for testing. Because it is an experimental preview, it requires a separate installation tool (such as AltStore or Sideloadly) on a computer to install onto your phone.

How do I back up my expenses?

Open Leaf, go to Settings → Data & Tools → Local & Cloud Backup, and tap Create Local Backup. This saves a copy of all your financial records directly onto your phone's storage.

How do I restore my backup?

In Leaf, go to Settings → Data & Tools → Local & Cloud Backup, tap Restore from Local File, and choose your previously saved backup file. All your transactions and settings will be restored instantly.

What should I do if the Android update does not install?

If the update does not install over your existing app, first ensure your data is backed up (Settings → Data & Tools → Local & Cloud Backup → Create Local Backup). Once you have confirmed your backup file is saved safely, remove the older version, install Leaf 1.1.4, and restore your data from Settings.

Can I install the iPhone version directly?

Not yet. The current iPhone package is an experimental preview that requires a sideloading tool on a computer to install. It cannot be installed simply by tapping the download link in Safari.
